Backlog y prioridades. Motor del Bomberman en canvas: movimiento, bombas, explosiones, colisiones, power-ups. Torneos.

UI completa: lobby, sala de espera, perfiles, leaderboard. Chat e interacción entre usuarios. Responsive, Privacy Policy, Terms of Service.

GitHub Issues, milestones, reuniones. Auth (registro, login, JWT). Perfiles, avatares, amigos. Estadísticas, historial, gamificación.
// Fases de desarrollo
1
Infraestructura base
Docker Compose con frontend, backend y postgres comunicándose. Base para que todo el equipo trabaje en local. (2-3 días)
2
Auth + usuarios
Registro, login, JWT, contraseñas hasheadas. Todo lo demás depende de esto. (1 semana)
3
Motor del juego ⚠️
Bomberman en canvas + Socket.io. Movimiento, bombas, explosiones, colisiones. Mayor riesgo técnico — atacarlo pronto. (2-3 semanas)
4
Lobby y sala de espera
Crear partida, unirse, lista de jugadores. Usa Socket.io ya montado. (1 semana)
5
Módulos sociales
Chat, amigos, perfiles, avatares, OAuth, 2FA. Relativamente sencillo con auth y WebSockets listos. (1 semana)
6
Módulos gaming + bonus
Torneos, personalización, estadísticas, gamificación, espectador, IA Opponent. (1-2 semanas)
7
Pulido final + README
Tests, Privacy Policy, Terms of Service, README completo con todos los apartados requeridos. Sin esto el proyecto es rechazado. (1 semana)
